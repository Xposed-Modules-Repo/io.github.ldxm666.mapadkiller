## 相比 2.1.2 的主要变化

**本版新增免 root 内置版**（见下一节）：不需要 root、不需要框架，装完就能用。本页下载的是**普通模块 APK**，两者同一套源码，修复内容完全一致。

- **「设置家」修复**：那条行由高德自己绘制、模块只负责放行，而首页面板实例被高德缓存复用，改开关不会重建。现在**写完立刻生效**（原地重建，不用退出重进），并且默认开启。
- **工具开关修复**：高德自己的工具槽只有两项，模块以前**只会删不会加**。现在按“已开启”自动补齐空位（首页工具栏实测只有 5 格），且只改首页那一份数据，不动高德自己的存储。
- **「更多工具」独立开关**：从「工具 → 其他」一百多个工具里提到**「首页」分组**，标签「更多工具入口」，工具分类顶部另加 5 格上限说明。
- **地图兴趣点开关修复**：原生库在集成模式下的布局与类加载器查找路径对不上、从未被加载，且原生侧把“没装成”报成了“装成了”。现在补齐加载路径、优先用宿主 `nativeLibraryDir`，并如实汇报（日志含 `framework_bound=`）。
- **开关写入即生效**：首页工具面板原地重建，原生样式过滤重新下发，不再需要“退出重进首页”。
- **推荐画布过滤加固**：卡名解析按宿主真实规则（`cardName`/`card_name`/`bizName`/`biz_name`/`name`），流式信封同时读 `is_done`/`isDone`、同时写 `has_more`/`hasMore`。
- **连带修复**：工具列表为空时不再把「设置家」行的父容器设为 `GONE`；尺寸换算精确复刻宿主 `dx1.l(v)=round(v/2*density)`；修复图标加载空指针并兼容 `iconToken`。
- **悬浮窗 UI 重做**：作者头像 + 状态胶囊 + GitHub 文字链，横向滑动切换分类（带边界回弹）、分类搜索、已开启工具排在最前。

## 免 root 内置版

不想装框架的话，本版把高德部分单独并入高德地图本体，提供了一个独立 APK：不需要 root、不需要 LSPosed、不需要任何框架，安装后打开高德，界面右侧常驻一颗悬浮球，点开就是全部高德设置。

- 适用 **高德地图 17.00.0.2005**，四 ABI；LSPatch v1.2 集成模式，内嵌原包与官方**逐字节一致**。
- 悬浮球是应用内浮层，**不申请任何权限**；退出高德即消失。
- **只处理高德**，不含百度 / 腾讯（代码在打包前就被删掉，不是运行时跳过）。
- ⚠️ 它用 LSPatch 重新签名，**与官方高德签名不同**：从官方版换过来必须先卸载官方高德（会清除登录态与离线地图）；已经是 2.1.3 内置版的可以直接覆盖安装。
- 下载：<https://github.com/ldxm666/MapAdKiller/releases/tag/v2.1.4> 的 `AMap-2.1.4-rootless-integrated.apk`。
- ⚠️ 它会被**安全中心 / 病毒扫描报红，这是误报**：包里内嵌了一个完整 APK（原版高德）、运行时从 assets 加载 dex、并内置签名绕过 —— 三点都来自重打包机制本身，无法通过"清理"消除。介意的话就用本页的模块版，它不改动任何地图安装包，不会被报毒。

## 安装与范围

安装 Release 中的 `MapClean-lsp-v2.1.4.apk`，已有用户可覆盖升级。在支持 libxposed API 102 的框架中启用模块，勾选需要处理的地图作用域，再进入模块设置调整开关，修改后强停对应地图并重新打开。

多数“显示……”设置为开启显示、关闭隐藏；标为“关闭……”或“去除……”的设置则是开启去除规则。工具栏总开关控制整个列表，“仅显示已开启工具”开启后只保留明确选中的工具，未知下发工具不自动加入。使用该模式时请先开启工具栏，再选中步行、骑行等所需项；要继续进入完整目录，请保留“更多工具”。**首页工具栏只有 5 格**，开第 6 个工具不会出现在那里。

## 功能范围

| 功能 | 高德 | 百度 |
| --- | --- | --- |
| 首页广告与营销流 | 天气、榜单、活动和推荐信息流控制 | 活动、任务横幅、推荐流、AI 此刻控制 |
| 底栏入口 | 列表、布局和点击目标同步 | 可见按钮与原生透明点击区同步 |
| 工具列表 | 步行、骑行、更多工具及仅显示选中工具模式 | 保留现有工具设置 |
| 地点详情照片推荐 | 独立隐藏“发现好去处”，保留地址、周边快捷工具与路线 | 本轮未新增详情推荐清理 |
| 搜索推广 | 保留现有搜索设置 | 热度飙升榜、推广词和推荐标签清理 |
| 底图兴趣点 | 整体显示开关，保留道路及城市名称 | 整体显示开关，保留道路及城市名称 |

地图兴趣点默认隐藏；搜索结果、收藏点、选点与导航提示可能作为独立业务图层继续显示。高德地点详情开关默认隐藏照片信息流，不清空地址和路线操作。

## 配置与升级

升级前建议导出配置。设置中的“保存配置／恢复配置”用于本地备份，“更多 → 导出／导入”用于 JSON 配置交换，覆盖高德、百度及模块设置。旧版仅含高德的配置可继续导入，缺失的百度设置不会被重置；旧地图标识分类会迁移为整体开关。导入后强停地图重开。

2.1.4 另有一次一次性迁移（`_amap_protocol_schema` 210 → 211）恢复「设置家」的默认值，只对“迁移前本来是开”的安装恢复，不会覆盖你显式做过的选择。

备份不包含地图账号、收藏、离线地图或框架作用域，更换设备时需重新勾选地图。发布 APK 与自行构建 APK 若签名不同，无法直接覆盖安装。

本轮主要实测高德 **17.00.0.2005**、百度 **22.0.0（1650）**，Android 16／LSPosed 2.1.1。免 root 内置版另在 Android 16 真机上完成覆盖安装与四项修复的逐条验证。Vector 2.2 完成公开接口与依赖检查，尚未在该框架实机复测；腾讯沿用原实现，本轮未验证。未知接口回退原应用行为，不承诺所有地图版本已适配。

## 常见问题与反馈

开关不生效时，先检查框架启用状态及作用域，再强停地图重开。工具显示还受工具栏总开关和“仅显示已开启工具”共同影响；首页工具栏只有 5 格。Vector 的等待连接、作用域读取失败和未勾选地图分别显示，不能将等待服务直接理解为未激活。地图标识对已经渲染的那份样式，需要重新进入地图页才完全生效。

刷新广告回流或底栏跳错页面仍可复现时，请在 [项目 Issues](https://github.com/ldxm666/MapAdKiller/issues) 提供模块、地图、Android、框架版本，相关开关状态与完整操作步骤。高德“其他”页和百度“诊断”可开启日志，复现后提取相关框架日志并关闭日志；免 root 内置版可直接用 `adb logcat | grep -E "MapAdKiller|MapCleanLabels"`。公开前遮挡账号、精确位置、路线、订单及令牌。
